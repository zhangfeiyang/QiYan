# 新手体验与界面更新（2026-09-19）

本轮以 Android App 为主，保留已有水墨、木质棋盘和字体修改，并同步小程序的难度规则。

## 已实现

- 15 档收敛到 5 档：轻松陪练、入门、进阶、高手、大师。新安装默认第一档。
- 前两档不再用强引擎的短时搜索伪装新手，而是有限判断和随机合法走法；第一档经常漏看吃子。提示、主动分析仍使用专业引擎。
- 旧难度偏好和闯关进度一次迁移。第一档为不计分练习，保留棋谱，悔棋不扣分。
- 首页突出开局，采用墨绿、暖金、纸感背景与本地绘制的棋子静物。对手以五个可读选项展示；小屏、英文及大字体的棋路选择可改为纵向。
- 每日一题按本地日期轮换题库，完成后记录累计及连续练习天数，同一天重复完成不重复计数，跨午夜旧题不计入新一天。
- 原创 64 秒器乐《松风入局》，音量调节和试听、淡入淡出、音频焦点处理、后台暂停。
- 落子涟漪、将军光环、收敛的吃子反馈；动画关闭及系统动画设置生效。
- 修复闯关“下一关”重复本关、提示取消及切换风格/难度时的搜索状态问题，防止失效回调改变新局。
